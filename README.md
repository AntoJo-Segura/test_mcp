# Auto-Sorpresa de Cumpleaños

This is a simple web application for organizing a surprise birthday party. Users can submit their name, email, and volunteer to help organize. The data is saved to a CSV file.

## Features

- Web form for user input (Name, Email, Volunteer Status)
- Data saved to `leads.csv`
- Basic HTML styling
- Confirmation page after submission
- Docker support for containerization
- Basic Terraform configuration for infrastructure management (example)

## Prerequisites

- Python 3.7+
- Flask (`pip install -r requirements.txt`)
- Docker (for containerized deployment)
- Terraform (for infrastructure management)

## Running the Application

### Directly with Python

1.  **Clone the repository (if you haven't already):**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```
2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Run the Flask application:**
    ```bash
    python app.py
    ```
    The application will be available at `http://localhost:5000` (or `http://0.0.0.0:5000`).

### Using Docker

1.  **Build the Docker image:**
    ```bash
    docker build -t birthday-surprise-app .
    ```
2.  **Run the Docker container:**
    ```bash
    docker run -p 5000:5000 birthday-surprise-app
    ```
    The application will be available at `http://localhost:5000`.

## Terraform Configuration

A basic Terraform configuration (`main.tf`) is included as an example. It uses the `local` provider to create an informational file.

1.  **Initialize Terraform:**
    ```bash
    terraform init
    ```
2.  **Apply the configuration:**
    ```bash
    terraform apply -auto-approve
    ```
    This will create a `terraform_info.txt` file in the project directory.

    **Note:** This Terraform configuration is a placeholder. For a real-world deployment, you would replace it with configurations for your chosen cloud provider and resources (e.g., VMs, databases, load balancers).

## LLM Assistant Microservice

This project includes a separate microservice designed to expose data from `leads.csv` to a Large Language Model (LLM) for tasks like generating a birthday party plan.

This microservice runs independently and has its own Docker configuration.

### Prerequisites for LLM Assistant Microservice

- Docker
- Access to the `leads.csv` file generated by the main application.

### LLM Assistant API Endpoints

The service (`llm_assistant_service/app_llm.py`) exposes the following GET endpoints:

-   **`/api/non_volunteers`**: Returns a JSON list of participants who are NOT volunteer organizers.
    -   Example: `[{"nombre": "Jane Doe", "email": "jane@example.com"}, ...]`
-   **`/api/volunteers`**: Returns a JSON list of participants who ARE volunteer organizers.
    -   Example: `[{"nombre": "John Smith", "email": "john@example.com"}, ...]`
-   **`/api/participant_count`**: Returns a JSON object with the total number of unique participants plus one.
    -   Example: `{"count": 11}`

### Running the LLM Assistant Microservice using Docker

1.  **Navigate to the microservice directory:**
    ```bash
    cd llm_assistant_service
    ```
2.  **Build the Docker image:**
    (Make sure you are inside the `llm_assistant_service` directory)
    ```bash
    docker build -t llm-assistant-service -f Dockerfile_llm .
    ```
3.  **Run the Docker container:**
    ```bash
    # Make sure your current directory is the project root (parent of llm_assistant_service)
    # This mounts the project root (containing leads.csv) to /csv_data inside the container.
    docker run -p 5001:5001 -v "$(pwd):/csv_data" llm-assistant-service
    ```
    The service will be available at `http://localhost:5001`.

    **Note on `leads.csv`:** The LLM assistant microservice requires the `leads.csv` file to be present. The Docker run command above shows how to mount the project's root directory (which should contain `leads.csv`) into the container so the service can access it.
